# M-HySMap v1.2 — Heavy-Run Harness

This package contains the M-HySMap v1.0/v1.1 algorithm code plus a new v1.2 experiment harness for paper-grade runs.

## What v1.2 adds

- JSON-driven experiment configs in `configs/`
- resume-safe per-run CSV files
- subprocess isolation for every `(config, seed)` run
- per-run timeout support
- stdout/stderr logs for debugging
- partial raw/summary/improvement CSVs refreshed after every completed run
- plot generation from the final/partial results

## Setup

```bash
unzip mhysmap_v12.zip
cd mhysmap_v12
python -m venv .venv
source .venv/bin/activate   # WSL/Linux/macOS
# Windows PowerShell: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Smoke test

```bash
python run_heavy_v12.py \
  --config configs/smoke_v12.json \
  --out-dir results/smoke \
  --timeout-per-run 300

python plot_heavy_v12.py --results-dir results/smoke
```

Expected smoke runtime: usually under a minute on a normal laptop.

## Paper-lite run

```bash
python run_heavy_v12.py \
  --config configs/paperlite_10seed_v12.json \
  --out-dir results/paperlite_10seed \
  --timeout-per-run 1800

python plot_heavy_v12.py --results-dir results/paperlite_10seed
```

This runs 4 configurations × 10 seeds = 40 subprocess-isolated runs.

## Heavy ASP-DAC run

```bash
python run_heavy_v12.py \
  --config configs/heavy_aspdac_v12.json \
  --out-dir results/heavy_aspdac \
  --timeout-per-run 3600

python plot_heavy_v12.py --results-dir results/heavy_aspdac
```

This is the big run. It may take a long time. The runner saves after every finished seed, so it can be interrupted and resumed.

## Resume behavior

Just run the same command again. Existing per-run CSVs in `results/<run>/per_run/` are skipped unless `--force` is passed.

```bash
python run_heavy_v12.py \
  --config configs/heavy_aspdac_v12.json \
  --out-dir results/heavy_aspdac \
  --timeout-per-run 3600
```

## Main outputs

After any run, the output directory contains:

- `mhysmap_v12_heavy_raw.csv` — all raw rows for every method/config/seed
- `mhysmap_v12_heavy_summary.csv` — aggregated means/min/max/std
- `mhysmap_v12_heavy_improvements.csv` — M-HySMap improvements vs baselines
- `mhysmap_v12_heavy_status.csv` — per-job status/timeout/failure log
- `mhysmap_v12_heavy_meta.json` — config and runtime metadata
- `logs/*.stdout.log`, `logs/*.stderr.log` — per-run logs
- `per_run/*.csv` — one CSV per config/seed

Plots generated by `plot_heavy_v12.py`:

- `mhysmap_v12_hops_grouped.png`
- `mhysmap_v12_improvements.png`
- `mhysmap_v12_incremental_speedup.png`

## Useful commands

Dry-run job list without executing:

```bash
python run_heavy_v12.py --config configs/heavy_aspdac_v12.json --out-dir results/heavy_aspdac --dry-run
```

Force rerun everything:

```bash
python run_heavy_v12.py --config configs/paperlite_10seed_v12.json --out-dir results/paperlite_10seed --force
```
