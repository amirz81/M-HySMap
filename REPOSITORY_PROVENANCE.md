# Repository provenance

This public package is derived from the user-supplied working snapshot:

`mhysmap_v13.zip`

The algorithm source, configurations, archived evidence CSVs/plots, and v1.3 optional add-on are
preserved. Public cleanup is limited to repository hygiene/documentation:

- removed Python bytecode/cache directories;
- removed redundant nested ZIP copies of already-extracted result folders;
- replaced the root v1.2 harness README with a paper-facing README;
- preserved the original v1.2 and v1.3 notes under `docs/legacy/`.

No scientific algorithm source was modified for the GitHub-ready package.
